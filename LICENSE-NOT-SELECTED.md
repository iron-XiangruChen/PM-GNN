# Licensing decision required from the code owner

No open-source license has been assigned automatically because the author must decide
which rights to grant. Before making the GitHub repository public, choose and add a
standard LICENSE file (for example MIT or Apache-2.0 if appropriate). If any borrowed
code or datasets have independent licenses, comply with their terms separately.

Until a license is explicitly selected, public visibility alone does not grant others
permission to reuse or redistribute the code.
