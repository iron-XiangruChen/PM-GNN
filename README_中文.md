## 首先阅读以下重要提醒

1. **文件命名标签过期**：现有保存的四组模型权重名称或配置写着 9个训练岩样/2个验证岩样，
   但实际执行输出明确记录8个训练、3个验证岩样（5777/2081图）。原因是原始代码的 `SPLIT_MODE`
   保存变量仍是旧文字，未随真正的 `split_method` 改变。不能据此认定权重实际使用9/2划分。
   本包只在未来重新训练所用的4个 notebook 中修正 `SPLIT_MODE = split_method` 元数据命名问题；
   保留作者提供的原权重文件名以兼容外部预测notebook。
2. **原始大型数据没有进入 GitHub 包**：包括11个CT原始体、裁剪结果、PNM孔喉Excel表，以及带本地绝对路径
   的原始 master CSV；所以这个仓库能公开代码，但尚不能在没有数据的情况下完整复现实验。
3. **性能开销**：所记录的训练总用时为GNN 655.97秒，完整PM-GNN 2562.39秒（约3.91倍），
   这里只反映训练耗时，不代表图构建＋路径提取＋推理的端到端时间。
4. **外部样品阈值**：以代码实际赋值为准，矿物砂岩0、Mt Simon 60、yulaiLR-SR 80、EF-78 70；
   训练11砂岩 0～60。你确认外部样品阈值根据各自灰度分布选择，而不是用物性标签反向调参。
5. **Mt Simon分辨率存在代码与正文不一致**：notebook实际变量2.25 μm，旁边注释/论文表格为2.8 μm；
   请在投稿和发布前核实当次实验实际输入分辨率。打包时没有擅自修改。
6. **权利问题**：目前没有替作者指定开源许可证；若要允许他人复用，请在GitHub另行添加 LICENSE。

## 代码目录

- `00_build_11_sandstone_dataset.ipynb`：生成11砂岩数字岩心的孔隙网络、渗流标签和弹簧网络代理力学标签。
- `01`至`04`：基础GNN、全局增强、路径增强、完整PM-GNN四个模型。
- `05`至`08`：三个独立砂岩及EF-78页岩外部验证。
- `09`：额外EF-75探索 notebook，并非正式论文所报告的EF-78数据。
- `checkpoints/*saved_tag_9train_2val/`：你提供的原始文件名带旧9/2标签的权重、训练日志及Scaler文件。

## 使用

安装建议环境：Python 3.10、TensorFlow 2.15.x；注意这不是当年训练时软件版本的证明。
RTX 4070 Ti 如果采用Windows，现代TensorFlow GPU更建议在WSL2/Linux中配置。

在仓库根目录运行：

```bash
pip install -r requirements.txt
jupyter lab
```

修改数据路径可以在命令行中设置 `PMGNN_DATA_ROOT`，外部CT用 `PMGNN_EF78_RAW` 等；
也可以打开notebook，在最前面的路径配置区直接改成当前电脑路径。
完整重建11砂岩时，注意生成代码里保留了原来的测试设置 `MAX_BLOCKS_PER_ROCK=10`，
需要改成 `None`，否则不会生成全样本。详见 `README.md` 和
`docs/KNOWN_LIMITATIONS.md`。

不宜直接把含有真实路径的原始 CSV、私人文件夹或大体积 CT/raw 加进公共 GitHub。
